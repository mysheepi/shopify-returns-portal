Column Reference

Row dimensions
SKUShopify variant SKU code.
ProductProduct family grouping. Used to roll up SKU-level data in the By Product view.
MonthCalendar month the order was placed (YYYY-MM). Filters and comparisons are always based on order month, not refund month.
TrialContractual return window: 30 days (standard) or 100 days (Home Pillow line). The clock starts from when the customer receives the order, not the order date. Since we only know the order date in Shopify, buffer days are added to approximate the delivery date.
Order volume
Ordered QtyTotal units fulfilled for this SKU in this order month. Only fulfilled line items are counted — cancelled or pending items are excluded.
30D Window & 100D Window
Returned QtyUnits where a formal return was registered by the customer within the window. Only physical returns (DHL label issued via Shopify) are counted — goodwill refunds where the customer keeps the item are excluded. Timing is measured from order date + buffer days (estimated delivery date).
Return RateReturned Qty ÷ Ordered Qty for this window, grouped by month of order (not month of return). This means an October refund for a February order is counted against February's rate. Red highlight when it exceeds the per-product threshold set in Settings.
Window Closed✓ when every order in this month has passed the return deadline (order date + buffer days for shipping + return window days) — the rate is final and no new returns can qualify. ✗ means some orders are still within their return window and the rate may still rise.
All Refunds (monetary)
Revenue €Total tax-inclusive revenue for this SKU × month after applied discounts. Used as the denominator for Refund Rate. Shipping fees are excluded.
Refunded €Total amount refunded to customers to date, tax-inclusive, regardless of when the refund was issued. Covers both physical returns and goodwill refunds. Shipping refunds are excluded.
Refund RateRefunded € ÷ Revenue €. Monetary return rate — comparable across SKUs at different price points and across months with different volumes.
Return Buffer (Settings)
Buffer daysApproximates the gap between order date and delivery date. Because return windows start from receipt (not order date), buffer days are added to the order date to estimate when the customer received the item. The effective return deadline is: order date + buffer days for shipping + return window days. Default: 10 days (estimated shipping time). Affects Returned Qty, Return Rate, and Window Closed for both windows.
